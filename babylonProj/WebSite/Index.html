Welcome to my BabylonJS Website

I am Denys Boichenko, a Games Development student exploring interactive 3D graphics with BabylonJS. This site showcases several coursework elements and links to my wider portfolio.

Interactive BabylonJS Elements

Each element is implemented as a separate BabylonJS scene and focuses on a specific feature of the framework:

  • Element 1 Experiments with primitive meshes and shapes.
  • Element 2 Stylised environment with simple props and layout.
  • Element 3 Keyboard input and simple gameplay logic.
  • Element 4 Basic third-person style player control.
  • Element 5 Interaction with multiple scenes.

You can open each element from the Elements drop-down menu in the navigation bar.
